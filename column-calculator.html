Enter the form diameter, the column height and how many you are pouring.

How it is calculated

Volume = pi x (diameter / 24)^2 x height in feet, times the number of columns.

Worked example

Four 12 in columns that are 8 ft tall need 4 x 3.14 x 0.25 x 8 = 25.1 cubic feet, about 0.93 yards before waste.

Frequently asked questions

What size Sonotube do I need?

Common sizes are 8, 10, 12 and 16 inches. The load and local code decide the size.
